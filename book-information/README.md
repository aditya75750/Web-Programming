# BookShelf — Book Information Website

A clean, human-designed academic web-programming project using classic HTML frames via nested `iframe` elements.

## Structure
- `index.html` — two-part home page
- `books.html` — left book list
- `details.html` — right book information panel

## Features
- Responsive layout
- Five book entries
- Click a book on the left to update the right panel
- No external libraries or dependencies
- Warm editorial/bookish visual style

Open `index.html` in a browser to run it locally.
